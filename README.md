# 📊 RGT — MVP de Contabilidade

Um dos meus primeiros projetos de desenvolvimento, criado com o objetivo de explorar a construção de uma aplicação web voltada ao contexto da contabilidade.

---

## 📌 Sobre o Projeto

O **RGT — MVP de Contabilidade** é um projeto desenvolvido como uma primeira experiência prática na criação de aplicações web utilizando Python e Django.

A proposta foi desenvolver uma aplicação inicial (*Minimum Viable Product — MVP*), colocando em prática conceitos de programação, organização de projetos e desenvolvimento web.

Mais do que o resultado final, este projeto representa uma etapa importante da minha trajetória como desenvolvedor.

---

## 🎯 Objetivo

Explorar o desenvolvimento de uma aplicação web relacionada à área contábil, aplicando os conhecimentos adquiridos durante meus primeiros contatos com o desenvolvimento de software.

O projeto também serviu como oportunidade para experimentar tecnologias, compreender a estrutura de uma aplicação Django e enfrentar desafios reais de programação.

## 🚀 Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/JP-GhOsT/RGT-MVP-de-Contabilidade.git
```

### 2. Acessar a pasta

```bash
cd RGT-MVP-de-Contabilidade
```

### 3. Criar um ambiente virtual

```bash
python -m venv venv
```

### 4. Ativar o ambiente virtual

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 5. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 6. Executar as migrações

```bash
python manage.py migrate
```

### 7. Iniciar o servidor

```bash
python manage.py runserver
```

Após iniciar o servidor, acesse:

```text
http://127.0.0.1:8000/
```
